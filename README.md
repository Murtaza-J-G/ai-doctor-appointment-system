# AI Doctor Appointment System

An AI-powered Doctor Appointment System built with Laravel, PHP, Filament, React, Inertia.js, Tailwind CSS, and Lucide React icons. 
The platform combines modern web technologies with the Gemini API to provide an AI assistant that 
helps users access intelligent healthcare-related assistance. It features a responsive user interface, a structured backend, 
and an administrative panel powered by Filament for efficient system management.

**Technologies Used:**
- **Backend:** Laravel, PHP
- **Admin Panel:** Filament
- **Frontend:** React.js, Inertia.js
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **AI Integration:** Google Gemini API

This project demonstrates full-stack web development, AI API integration, and the development of modern healthcare appointment management applications.
